# Urban Bike Landing Page

A responsive landing page for an urban bike brand. The website presents bike
models and their key features and provides a contact form for potential
customers.

## Live Preview

[View the live website](https://chumachenkoUA.github.io/urban-bike-landing/)

## Design Reference

The landing page is based on the
[MYBIKE Figma design](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1).

## Technologies Used

- HTML5
- SCSS
- JavaScript
- BEM methodology
- Parcel
- GitHub Pages

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/chumachenkoUA/urban-bike-landing.git
cd urban-bike-landing
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Mobile navigation menu
- Smooth scrolling between page sections
- Interactive hover effects and subtle animations
- Contact form with input validation
- Optimized WebP images with lazy loading
- Accessible navigation controls
